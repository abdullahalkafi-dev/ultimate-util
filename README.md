# Ultimate Util

A fast, searchable platform of everyday developer, designer and document tools.
Most tools run entirely in the browser; a few sync to your account after Google login.

- `frontend/` Next.js app (TypeScript, Redux Toolkit, RTK Query)
- `backend/` Fastify API (TypeScript, Mongoose)
- `shared/` shared types and API schemas
- `docs/` product specs and decisions

See `docs/` for the feature specs and architecture notes.
