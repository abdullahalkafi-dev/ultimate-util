# Audit 1 (2026-11-19)

Scope: the tool work written after the first handoff (all 33 tools now have a screen and are registered live).

## Passed
- Typecheck clean in shared, backend and frontend.
- 552 frontend unit tests pass (47 files).
- Privacy: the only network calls are cloud tools calling our own `/api/v1`, the background remover loading its model from our origin, and sample text in the cURL generator. EXIF map is an opt-in link.
- XSS: every `dangerouslySetInnerHTML` goes through DOMPurify or an escape function.
- 2FA secrets stay in memory and are wiped when the vault locks.

## Fixed during the audit
- Lint: generated files in `frontend/public/vendor` were linted (about 3,500 false errors). They are now ignored. About 30 real errors fixed (unused imports and variables, a float literal that lost precision, an unused-expression, copy-assets). Stub plugins registered for the inline `react-hooks` and `@next/next` disable comments. Lint: 0 errors.
- The work was uncommitted. It is now committed one tool at a time.
