# Audit 2 (2026-11-26): build, Docker and browser testing

Follows [audit 1](2026-11-19-audit-1.md). This one closes the "production build" and "never opened in a browser" items.

## State
All 33 tools have a screen, are registered live and are committed. Lint 0 errors, typecheck clean, 552 frontend tests and 21 backend tests pass. `docker compose up` builds and runs the whole stack (mongo, backend, frontend). All 33 tool pages load in headless Chromium with no console errors and no requests to other origins.

## Production build
`next build` with Turbopack hung forever on this codebase. `next build --webpack` finished and printed the real errors Turbopack hid, now fixed:
- A CSS module used `::highlight(...)`; the rules moved to `globals.css`.
- The qpdf wasm glue imported Node's `fs`; browser stubs were added in `next.config.ts`.
The build script uses `--webpack` (see decisions log). `NEXT_DIST_DIR` lets you build into a second folder.

## Docker
Fixed: pnpm refused the install scripts of protobufjs and tesseract.js (declined in `pnpm-workspace.yaml`), and the backend host port is now configurable (`BACKEND_HOST_PORT`). On Windows run builds with `BUILDX_BAKE_ENTITLEMENTS_FS=0`.

## Browser testing (Playwright, four testing agents)
Every tool was used end to end, not just loaded. All pass. Bugs found and fixed:
- Video tool: cross-origin isolation headers blocked the ffmpeg worker, then webpack broke the worker's dynamic import. The worker is now copied to `/vendor/ffmpeg/worker`. A real GIF was produced afterwards. Also fixed a timeout and webm duration handling.
- PDF tools: pdf.js v6 needs `Uint8Array.prototype.toHex` (Chrome 140+). Switched to the pdf.js legacy build.
- Cron parser: two hydration mismatches (run times, timezone list). Wording of the day-of-month OR day-of-week warning.
- Saved palettes: hydration mismatch (guest banner now after mount).
- Clipboard drop: "Add files" never staged files (live FileList emptied).
- Unit converter: "5 km in miles" and similar were parsed as time zones.
- Snippet dialog: Save unreachable on short screens; shared `.dialog` now scrolls inside the viewport.
- Bulk resizer: oversize SVG jobs were silently marked done.
- Guests no longer trigger a 401 request on every page.

## Known limits and open items
- Background remover "AI" mode needs an ONNX model that is not bundled (licence). Fast cutout works.
- Not tested: quotas (1000/500/200/100), live webcam QR scan, snippet "delete forever", pomodoro settings tab, password-protected `.doc` input to the DOCX editor, non-English OCR, very large files.
- JSON to XML emits `<@id>` for a key named `@id` (invalid tag); palette export names like `--color-color-1`; library import does not dedupe.
- Google OAuth is still untested (no credentials). Atlas, deployment and the 47 open questions still wait on the owner.
- Real-device and Safari/Firefox testing has not been done; all browser tests ran in Chromium.
